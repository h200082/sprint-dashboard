# Quantico 대시보드 수정 학습 시작하기

## 1. 자동 반영되는 개발 화면 열기

VS Code에서 이 프로젝트 폴더를 연 뒤 상단 메뉴의 `터미널 → 새 터미널`을 누릅니다.

PowerShell 터미널에 다음 명령을 입력하고 Enter를 누릅니다.

```powershell
npm.cmd run dev
```

터미널에 표시된 `http://localhost:3000` 주소를 브라우저에서 엽니다. 이 터미널은 학습하는 동안 닫지 않습니다.

## 2. 한 가지 값만 바꿔 보기

1. `app/page.tsx` 파일을 엽니다.
2. `Ctrl+F`를 누르고 `직접 수정 1`을 검색합니다.
3. `title: "Nominal Balance"`의 따옴표 안쪽만 원하는 글자로 바꿉니다.
4. `Ctrl+S`로 저장합니다.
5. 브라우저가 보통 1~2초 안에 자동으로 바뀌는지 확인합니다.

이 자동 반영 기능을 HMR(Hot Module Replacement)이라고 합니다.

## 3. 화면이 자동으로 바뀌지 않을 때

1. 개발 서버를 실행한 터미널이 아직 열려 있는지 확인합니다.
2. 터미널에 빨간 오류가 있다면 가장 위의 파일명과 줄 번호를 확인합니다.
3. 마지막 수정에서 따옴표, 쉼표, 괄호가 사라지지 않았는지 확인합니다.
4. 해결이 어렵다면 `Ctrl+Z`로 마지막 수정을 되돌리고 다시 저장합니다.
5. 오류가 없는데도 그대로라면 브라우저를 한 번 새로고침합니다.

## 4. 배치 공부는 이 순서로 해보세요

`app/page.tsx`에서 `Ctrl+F`를 누르고 아래 주석 이름을 검색하면 수정할 코드 바로 위로 이동합니다.

1. `직접 수정 4`에서 KPI 카드의 `gap-2`를 `gap-4`로 바꿔 카드 간격을 비교합니다.
2. `직접 수정 3`에서 상단 비율을 `1fr : 1fr`에서 `1fr : 1.2fr`로 바꿉니다.
3. `직접 수정 9`에서 중단 비율을 `1.43fr : 1fr`에서 `1fr : 1fr`로 바꿉니다.
4. `직접 수정 5`에서 전체 최대 너비를 1440px에서 1200px로 바꿉니다.
5. 브라우저 폭을 줄였다 늘리면서 `sm:`, `md:`, `min-[900px]:`가 적용되는 순간을 관찰합니다.
6. 마지막에 MetricCard의 `높이를 바꿀 때 꼭 알아둘 계산` 주석을 읽고 카드 높이를 실습합니다.

각 주석에는 바꿀 클래스, 바뀐 뒤 보이는 결과, 함께 고쳐야 하는 값이 적혀 있습니다.
처음에는 한 번에 한 값만 바꾸고 화면을 확인한 다음 다음 실습으로 넘어가세요.

## 5. 어느 파일을 수정해야 하나요?

- 내용·숫자·카드 배치: `app/page.tsx`
- 전체 배경과 공통 색상: `app/globals.css`
- 모든 Card·Button 등의 공통 기본 모양: `components/ui`
- 각 파일의 역할 찾기: `docs/FILE_ROLES.md`

처음에는 `components/ui`보다 `app/page.tsx` 안의 데이터와 className만 수정하는 것이 안전합니다.
